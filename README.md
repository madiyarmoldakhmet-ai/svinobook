# SvinoBook 📱
Cross-platform social networking app built with Flutter & Firebase. Features real-time messaging, user profiles, and content sharing.
## 🚀 Quick Start
```bash
git clone https://github.com/madiyarmoldakhmet-ai/svinobook.git
cd svinobook
flutter pub get\nflutter run
```
## 🛠 Tech Stack
- **Flutter** + **Dart** — cross-platform UI\n- **Firebase** — auth, database, storage\n- **Cloud Firestore** — real-time sync
