## 💡 About The Project

**SvinoBook** is a modern cross-platform social networking application designed for high performance, smooth animations, and real-time data synchronization.

<br>

## ✨ Key Features

| Module | Description | Tech Stack |
| :--- | :--- | :--- |
| 💬 **Real-Time Messaging** | Instant, zero-latency chat delivery | Cloud Firestore, Streams |
| 👤 **User Profiles** | Custom profile setup, avatars, and bios | Firebase Auth, Storage |
| ⚡ **Content Sharing** | Post feeds, media sharing, and instant likes | Firebase Realtime Sync |
| 🎨 **UI / UX** | Fluid, responsive design across all devices | Flutter Material 3 |

<br>

## 🛠 Tech Stack

* **Frontend:** Flutter & Dart (Cross-Platform UI)
* **Backend & BaaS:** Firebase Auth, Cloud Firestore, Firebase Storage
* **State Management:** Provider / BLoC

<br>

## 🚀 Quick Start

Ensure you have **Flutter SDK** and **Git** installed on your system, then run the following commands in your terminal:

```bash
# 1. Clone the repository
git clone [https://github.com/madiyarmoldakhmet-ai/svinobook.git](https://github.com/madiyarmoldakhmet-ai/svinobook.git)

# 2. Navigate to project directory
cd svinobook

# 3. Get packages
flutter pub get

# 4. Run the app
flutter run
